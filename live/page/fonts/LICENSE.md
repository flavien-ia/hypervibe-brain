# The fonts of the live view

These fonts are loaded only by the Hypervibe design of the live view
(`theme-hypervibe.css`), from this folder: nothing is downloaded, the view
shows them without a network. They are the fonts of the Hypervibe design
system, unchanged; only their file names were made clearer.

| File | Font | Author | Licence |
|---|---|---|---|
| `geist-variable.woff2` | Geist, variable (weights 100 to 900) | Vercel, with basement.studio | SIL Open Font License 1.1, full text in `LICENSE-Geist.txt` |
| `geist-mono-variable.woff2` | Geist Mono, variable (weights 100 to 900) | Vercel, with basement.studio | SIL Open Font License 1.1, full text in `LICENSE-Geist.txt` |
| `archivo-latin.woff2` | Archivo, variable (weights 100 to 900, widths 62 % to 125 %), Latin subset | The Archivo Project Authors (Omnibus-Type, https://github.com/Omnibus-Type/Archivo) | SIL Open Font License 1.1 |
| `archivo-latin-ext.woff2` | Archivo, the same, Latin Extended subset | The Archivo Project Authors (Omnibus-Type) | SIL Open Font License 1.1 |

Archivo: Copyright 2016 The Archivo Project Authors
(https://github.com/Omnibus-Type/Archivo). Its licence is the same SIL Open
Font License, Version 1.1, whose text is in `LICENSE-Geist.txt` (from its
preamble on) and at https://openfontlicense.org.
